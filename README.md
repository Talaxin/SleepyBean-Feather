# SleepyBean (Feather)

Public IPA source for [Feather](https://github.com/claration/Feather). This repo has **no app source** — only the signed-ready IPA and AltStore JSON.

## Add in Feather

Sources → Add Source:

```
https://raw.githubusercontent.com/Talaxin/SleepyBean-Feather/main/app-repo.json
```

Then install **SleepyBean 1.5.1.39**. After the iPhone install, open the Watch app → Available Apps → Install SleepyBean. Open SleepyBean on the phone first so the Watch can copy the log.
